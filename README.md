## 2. Features

### 2.1 Merge Backup
The Backup will override the old Backup each time. Less Memory is needed than other Backup Features. 
The feature provides adjusting the Local Date Time and source and target path for the Backup.
You can make infinite Backup instances. The instances are shown in the overview Window of the tool.
